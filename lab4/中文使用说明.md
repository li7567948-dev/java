# Lab 4 使用说明

1. 解压整个 lab4 文件夹。Eclipse：File → Import → General → Existing Projects into Workspace，选择 lab4。
2. 打开 src/controller/Main.java，右键 Run As → Java Application。项目编码 UTF-8，工作目录必须为 lab4 根目录。JDK 8 或更新版本。
3. 输入用户名 root，回车；密码 lab4，回车。自动测试会先运行，再显示俄语菜单。
4. 菜单 4 读取文件，5 保存，6 添加（可一次添加多辆），7 修改指定 ID，8 删除指定 ID，9 显示列表，10 按 ID 查询，11 切换调试，12 自动测试，0 退出。1–3 是之前的车辆检查与排队模拟。
5. 第一次运行会创建 data/vehicles.txt（五辆示例车辆）；修改和删除立即保存。logs/application.log 每次运行都追加记录。
6. 普通用户演示：Eclipse Run Configurations → Arguments → Program arguments 填 config-user.properties。登录 operator，密码 lab4。11、12 菜单不显示，直接输入也会被拒绝。配置中 autotests=true 仍会自动执行测试。
7. results 文件夹是真实测试输出，非预设结果。测试使用临时文件，不会删除你正常使用的数据库。

Windows 命令行也可运行 run_windows.bat，需要电脑已安装 JDK 并配置 PATH。不要把本工程的 src 和旧 Lab2/3 混合。默认密码仅为实验演示。
