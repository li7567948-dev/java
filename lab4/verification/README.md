Внешний проверочный сценарий Python 3 (не зависимость приложения). После компиляции исходников в bin выполнить из корня проекта: `python verification/check_interactive.py bin`. Каждый сценарий запускается в отдельном временном рабочем каталоге; сценарии CRUD и перезапуска используют одну временную БД. Вывод записывается в results. Программа Java не требует Python для запуска.
