# Java 实验3：重新制作的 Eclipse 项目

## 为什么和上一版不一样

上一版实验3重新创造了 `Driver`、`InspectionLane`、`PassengerCar` 等类，与已有实验2的代码结构不同。这次完全改回实验2中实际存在的主程序和类关系：

- `Car` / `Truck` / `Bus` / `Trailer` / `CarWithTrailer` 继承 `Vehicle`。
- `CheckPoint` 表示单个检查点；`Simulation` 管理检查点、车辆队列和事件，是实验3两个集合中保存的主对象。
- 保留实验2原来的汽车参数、5种车辆限制、危险货物判断、通行结论和菜单1～3。
- 新增的实验3功能在独立的 `BenchmarkService`、`SolvabilityService`、`Lab3ObjectGenerator`、`ErrMsgLog` 中实现，避免改乱实验2业务逻辑。

## 在 Eclipse 里正确导入

**不要把新文件逐个复制到旧的 lab3 文件夹里。** 旧版有同名 `Bus.java` 和不同结构，混在一起很容易再次出现多个编译错误。

1. 将新的 ZIP 解压，找到里面含有 `.project` 的 `lab3` 文件夹。
2. 如果 Eclipse 已经打开旧 `lab3` 工程：右键旧工程 → `Delete`，**取消勾选“Delete project contents on disk”**，只从工作区移除旧工程。
3. Eclipse → `File` → `Import` → `General` → `Existing Projects into Workspace`。
4. 点 `Select root directory`，选择解压后的 `lab3` 文件夹 → `Finish`。
5. 选择 `Project` → `Clean...` → 选择 `lab3` → `Clean`。
6. 打开 `src/controller/Main.java` → 右键 `Run As` → `Java Application`。
7. 默认打开菜单，选 `4` 运行10份日志、选 `5` 测试可解决性、选 `6` 测试 ArrayList 扩容。
8. 如果 Eclipse 使用的不是 UTF-8，右键项目 → `Properties` → `Resource` → `Text file encoding` → `UTF-8`。
