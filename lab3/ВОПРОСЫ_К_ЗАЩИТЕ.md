# Контрольные вопросы к ЛР № 3

1. **Исключение в Java** — объект, сообщающий о нарушении нормального выполнения программы; обработка через `try` / `catch`.
2. **Что можно перехватить?** Исключения, наследующие `Throwable`, в обычных условиях могут обрабатываться; ошибки VM (`VirtualMachineError` и др.) не следует использовать как штатные восстановимые ситуации.
3. **`finally`** — блок освобождения ресурсов при выходе из `try` / `catch`; предпочтителен `try-with-resources` для закрываемых ресурсов.
4. **Как создать исключение?** `throw new IllegalArgumentException("...");`.
5. **Как передать исключение выше?** Объявить `throws IOException` в сигнатуре метода либо повторно вызвать `throw`.
6. **Коллекция** — структура данных из Java Collections Framework для хранения и перебора набора элементов.
7. **Рост `ArrayList`** — динамическое изменение внутреннего массива. Конкретный коэффициент роста не гарантирован API; формула методички относится к старым реализациям.
8. **Рост `LinkedList`** — добавление новых узлов, а не увеличение ёмкости единого массива.
9. **`ArrayList` vs `LinkedList`** — `ArrayList` обычно O(1) для доступа по индексу и O(n) для вставок/удаления в середине; `LinkedList` O(n) для поиска по индексу, O(1) для добавления у известного узла (не учитывая поиск).
10. **Ассоциативные массивы** — `Map<K,V>` хранит пары «ключ–значение». `HashMap` без гарантированного порядка, `LinkedHashMap` — порядок вставки, `TreeMap` — сортировка по ключу, `WeakHashMap` — слабые ссылки на ключи.
11. **Итератор** — стандартный обход коллекции без необходимости прямого доступа по индексу, с возможностью безопасного удаления через `Iterator.remove()` при соблюдении правил итератора.
