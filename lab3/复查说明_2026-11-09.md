# Java 实验3 —— 再次复查说明（2026-11-09）

## 本次查出并修复的问题

1. **可解决性误判：** 以前只测试原顺序和最短检查时间优先，可能错过真实可行的顺序。现在额外测试最长时间优先，并在判断失败时说明仅代表已测试的方案，没有证明其他顺序绝对不可能。
2. **正在使用的检查通道可被直接关闭：** 修复 `CheckPoint.setOpen`，拒绝关闭繁忙通道。
3. **性能结论遗漏中位数比较：** 现在 `results/summary.csv` 与俄语结论中，均包含并比较 Total / Average / Median。
4. **ArrayList 容量实验不够严谨：** 现在直接测量有足够容量和明确需要扩容的两种 `add`，旧教材公式只作理论对照，不冒称是现代 JDK 的实际容量。
5. **解析模式会改动原始车辆对象：** 现在使用 `VehicleFactory.copyOf`，不修改原车辆的到达时间与检查结果。
6. **演示固定参数：** 原先菜单5只能显示固定示例，现在可以选择随机车辆数、有效通道、已安装通道与截止时间进行演示；CLI `--solvability` 仍保留不需要输入的固定示例。
