Исследование времени ArrayList.add при увеличении ёмкости
Формула из пособия: (oldCapacity * 3) / 2 + 1
Проводятся 160 парных измерений для каждой начальной ёмкости.
Оба списка создаются как new ArrayList<>(oldCapacity).
Без роста: add при size = oldCapacity-1 (список ещё не заполнен).
С ростом: add при size = oldCapacity (добавляется oldCapacity+1-й элемент).
Следующий размер из старой формулы — расчётный, НЕ подтверждённый размер JVM.
