Времена взяты из реального файла ArrayList_10000.log. Единица: нс.
Индекс = число добавленных элементов ДО очередной операции add.

Старая формула из задания: (oldCapacity * 3) / 2 + 1
Современная приблизительная схема: new = old + old/2
ВАЖНО: ArrayList не предоставляет публичный getter для capacity.
Время операции само по себе не доказывает значение внутренней ёмкости.
На время влияют JIT-компиляция, GC и планирование потоков.
